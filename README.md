# LINUX DO 新帖列表 AI 智能总结

油猴用户脚本(v1.9.0)。在 `https://linux.do/latest` 等列表页注入一个可拖动悬浮球,一键抓取当前列表页帖子,交给任意 OpenAI 兼容接口做主题分类、一句话摘要与整体概览,点击卡片直达原帖。

## 安装

1. 浏览器安装 Tampermonkey / Violentmonkey。
2. 新建脚本,粘贴发布版 `linuxdo-ai-summary.release.user.js` 全部内容并保存(无注释,功能与源码版完全一致);需要读源码时用 `linuxdo-ai-summary.user.js`。
3. 打开 `https://linux.do/latest`,右下角出现悬浮球(带当前列表帖子数徽标)。

脚本带域名硬限制:仅 `linux.do` 及其子域可用。即使把 `@match`/`@include` 改成其他论坛,三个模块也会在运行时自检域名后直接退出,不注入 UI、不挂钩网络请求。

## 使用

1. 点悬浮球 → 底部半屏面板。
2. 点齿轮展开配置,填 API 通道、抓取条数与屏蔽规则(配置保存在本地)。
3. 点「总结」,进度条显示批次进度。
4. 结果 = 今日概览 + 按主题分组的卡片;点卡片在新标签打开原帖。
5. 面板顶部是分类快捷入口(开发调优/福利羊毛/搞七捻三/快问快答/人工智能/原创/NSFW/软件开发/DeepSeek):点分类跳转对应版块,落地后自动弹出面板,再点「总结」即总结该分类;当前分类高亮。最上方一行是更大更醒目的星标特殊链接(人工智能/软件开发/开源推广),点击直达并自动总结。
6. 配置里的「屏蔽标题关键字 / 屏蔽用户」:输入后点「添加」或按回车加入列表(支持一次粘贴多个,中英文逗号/顿号/分号分隔),列表条目点 × 删除,增删后点「保存配置」持久生效;标题包含关键字、或作者命中用户名的帖子在总结时直接剔除,规则只作用于总结结果,不改动论坛页面。
7. 配置面板「板块与分类规则」(默认折叠)里可自定义四类规则:福利白名单/黑名单关键字(白名单命中的帖子必进总结,仅在福利羊毛版块生效,清空白名单则该版块不过滤、全部总结);特殊链接(面板最顶部醒目星标入口,名称 + 版块路径);分类快捷入口(名称 + 版块路径,保存后顶部入口即时重建);标签归一分组(分组名 + 同义词,AI 的同义写法归到同一分组)。
8. 打开面板自动出结果:同版块 30 分钟内的缓存直接展示,过期或无缓存时后台自动总结,不用手点「总结」;可在配置里关闭。
9. 「为你推荐」:点开的帖子会记录兴趣(标题分词/分类/标签,仅存本地、不上传),之后的总结把最高分的未读帖子置顶成「★ 为你推荐」组;可在配置里关闭或一键清空记录。
10. 再点一次悬浮球或 ✕ 收起;运行中关闭会取消剩余请求。

分类入口、福利关键字、标签分组的内置默认值在脚本头部常量(`QUICK_CATEGORIES` / `WELFARE_KEYWORDS` / `TAG_ALIASES`)里;配置面板保存过自定义后,以自定义为准。

## 实现结构

```
悬浮球 → 底部半屏面板(配置区 / 进度 / 结果区)
   ↓ 总结
1 抓帖:discourse → discuz → generic 三层降级 DOM 解析;总结前先过自定义屏蔽(标题关键字/用户)与板块策略过滤
2 分批:单批最多 40 条,单批最多 9000 字符,双阈值先到先分
3 请求:OpenAI 兼容 /chat/completions,3 并发 + 失败重试 1 次
4 解析:剥离 markdown 围栏 → 截取 JSON → 尾逗号/截断/单引号修复
5 合并:按序号回填 + tag 同义归一化(技术/教程/资源福利/求助/分享/闲聊/公告/其他)
6 渲染:概览 + 分类卡片(原生 <a target="_blank"> 跳转)
```

批次结果带内存缓存(同 API + 同模型 + 同标题集合直接复用),失败批次只计失败,不丢已成功结果;关闭面板即中止请求并清理定时器与事件监听。

## 已知限制

- 域名硬限制是客户端自检:改 `@match` 换站无效;但拿到源码的人可以删掉检查再运行,纯前端脚本无法对抗源码级修改,这是所有客户端脚本的共同边界。
- 代码内嵌署名铅封(加密指纹 + 校验,接线在域名闸之后):删除或篡改铅封数据/密钥/指纹,脚本在所有站点整体停摆;同样是客户端自检,防"顺手删署名",不防"连检查一起删"的源码级修改。
- 条数上限 500;Discourse 每页 30 条,超过当前页时开启「自动滚动加载」会滚动页面拉取,拉不到就按已抓取数量处理。
- 标签页在后台或被其他窗口完全遮挡时,浏览器暂停渲染,Discourse 的懒加载哨兵不会触发;此时脚本直接跳过滚动加载,并在状态栏提示,按当前已抓取数量继续。
- 摘要基于标题/分类/标签/热度生成,`/latest` 列表页本身没有正文摘要;想要更准的正文级摘要,需要额外请求每个主题的 JSON 接口。
- 油猴环境下用 `GM_xmlhttpRequest` 直连,可绕过 CORS;没有脚本管理器时退回 `fetch`,跨域会被浏览器拦截。
- 整体概览是额外 1 次请求,失败不影响分类结果展示。
- 手机浏览器点击卡片是原生链接跳转,不依赖 `window.open`,不会被弹窗拦截逻辑卡住。

## 开发

- `node --check linuxdo-ai-summary.user.js` 做语法检查。
- `node build.js` 从源码生成无注释发布版 `linuxdo-ai-summary.release.user.js`(保留 `==UserScript==` 头,剥离其余全部注释);源码改动后需重新构建。
- `node test-board.js` / `test-channels.js` / `test-integration.js` / `test-domain.js` / `test-release.js` 跑本地测试(需 `npm i --no-save jsdom`)。
- `_probe.js` / `_probe2.js` / `_test.js` / `_test2.js` / `_layout.js` / `_smoke.js` 是在真实页面注入后的探针与端到端用例(`agent-browser-cli exec --tab <id> --file <path>`),验证通过后可以删除。
