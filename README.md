# LINUX DO 新帖列表 AI 智能总结

油猴用户脚本(v1.1.0)。在 `https://linux.do/latest` 等列表页注入一个可拖动悬浮球,一键抓取当前列表页帖子,交给任意 OpenAI 兼容接口做主题分类、一句话摘要与整体概览,点击卡片直达原帖。

## 安装

1. 浏览器安装 Tampermonkey / Violentmonkey。
2. 新建脚本,粘贴 `linuxdo-ai-summary.user.js` 全部内容并保存。
3. 打开 `https://linux.do/latest`,右下角出现悬浮球(带当前列表帖子数徽标)。

其他 Discourse 站点在脚本头部自行追加一行 `@match`,例如 `// @match https://meta.discourse.org/*`;Discuz 站点(如 `bbs.binmt.cc`)也会自动切到对应的解析 profile。

## 使用

1. 点悬浮球 → 底部半屏面板。
2. 点齿轮展开配置,填 API 地址 / Key / 模型 / 条数(配置保存在本地)。
3. 点「总结」,进度条显示批次进度。
4. 结果 = 今日概览 + 按主题分组的卡片;点卡片在新标签打开原帖。
5. 面板顶部是分类快捷入口(开发调优/福利羊毛/搞七捻三/快问快答/人工智能/原创/NSFW/软件开发/DeepSeek):点分类跳转对应版块,落地后自动弹出面板,再点「总结」即总结该分类;当前分类高亮。
6. 再点一次悬浮球或 ✕ 收起;运行中关闭会取消剩余请求。

分类入口在脚本头部 `QUICK_CATEGORIES` 常量里维护,按 `{ label, path }` 增删即可。

## 实现结构

```
悬浮球 → 底部半屏面板(配置区 / 进度 / 结果区)
   ↓ 总结
1 抓帖:discourse → discuz → generic 三层降级 DOM 解析
2 分批:单批最多 40 条,单批最多 9000 字符,双阈值先到先分
3 请求:OpenAI 兼容 /chat/completions,3 并发 + 失败重试 1 次
4 解析:剥离 markdown 围栏 → 截取 JSON → 尾逗号/截断/单引号修复
5 合并:按序号回填 + tag 同义归一化(技术/教程/资源福利/求助/分享/闲聊/公告/其他)
6 渲染:概览 + 分类卡片(原生 <a target="_blank"> 跳转)
```

批次结果带内存缓存(同 API + 同模型 + 同标题集合直接复用),失败批次只计失败,不丢已成功结果;关闭面板即中止请求并清理定时器与事件监听。

## 已知限制

- 条数上限 500;Discourse 每页 30 条,超过当前页时开启「自动滚动加载」会滚动页面拉取,拉不到就按已抓取数量处理。
- 标签页在后台或被其他窗口完全遮挡时,浏览器暂停渲染,Discourse 的懒加载哨兵不会触发;此时脚本直接跳过滚动加载,并在状态栏提示,按当前已抓取数量继续。
- 摘要基于标题/分类/标签/热度生成,`/latest` 列表页本身没有正文摘要;想要更准的正文级摘要,需要额外请求每个主题的 JSON 接口。
- 油猴环境下用 `GM_xmlhttpRequest` 直连,可绕过 CORS;没有脚本管理器时退回 `fetch`,跨域会被浏览器拦截。
- 整体概览是额外 1 次请求,失败不影响分类结果展示。
- 手机浏览器点击卡片是原生链接跳转,不依赖 `window.open`,不会被弹窗拦截逻辑卡住。

## 开发

- `_probe.js` / `_probe2.js` / `_test.js` / `_test2.js` / `_layout.js` / `_smoke.js` 是在真实页面注入后的探针与端到端用例(`agent-browser-cli exec --tab <id> --file <path>`),验证通过后可以删除。
